# 闲庭斗地主

Flutter + Flame 中文离线斗地主：一名玩家与两名本地电脑对战，支持 Windows 10+ x64、Android 15+ ARM64 手机/折叠屏/平板及 Web。无账号、广告、联网对战或真钱功能。

支持经典叫分、完整牌型、提示出牌、炸弹与春天结算、轻松/标准难度、最近 20 局战绩，以及三道独立记录通关状态的残局练习。

[在线试玩](https://qpzm7903.github.io/flutter-game/) · [下载各平台版本](https://github.com/qpzm7903/flutter-game/releases)

点击手牌选中后出牌；提示只选牌，仍需确认。右上角菜单包含重新发牌、难度设置、最近战绩、残局练习、玩法和诊断。难度设置从下一局生效，练习不计入普通积分与战绩。

## 日志与本地资料

Windows 日志位于 `%USERPROFILE%/.xianting-doudizhu/logs/doudizhu.log`，Android 位于应用文档目录下 `logs/doudizhu.log`，原生日志约 1 MiB 后轮转并保留一个备份。Web 使用浏览器本地存储保留约 64K 字符日志，可从诊断弹窗下载。诊断界面可查看路径与复制内容，不上传日志。

难度、总战绩、最近记录和通关状态使用本机快照保存；兼容早期版本资料。清除应用数据或浏览器站点数据会删除这些记录。

## 构建与验证

仅在 `main` 开发，Flutter 分析、测试和构建全部在 Actions 执行，本地无需安装 SDK。首版参考 [flutter-snake](https://github.com/g-ai-002/flutter-snake)（MIT），保留授权与 GitHub/Gitea 构建发布结构；Android SDK 为 min 35 / target 37 / compile 37。

Web ZIP 解压后用静态服务器访问，支持任意目录；渲染资源和中文后备字体随包提供。Noto Sans SC 字体采用 OFL，许可位于 `assets/fonts/OFL.txt`。

验证覆盖完整模拟牌局、全部牌型、320/360/800/1400 宽度布局、资料迁移和保存恢复、三题解法及错误路线、日志轮转，以及浏览器实际操作。最新进度和 CI 证据见 [plan.md](plan.md)。Windows/Android 已在 CI 构建，尚未进行本次环境中的真机安装测试。
